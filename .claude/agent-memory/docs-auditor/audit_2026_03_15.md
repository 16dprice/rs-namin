## Issues Found and Fixed

### docs/module_layout.md — pseudocode inaccuracies (fixed)

Three pseudocode lines were stale relative to `src/viewer.rs`:

1. `scrub_bar.update(&mut clock)` — actual call is `debug.update(&mut clock)` which internally delegates
2. Separate "handle debug keybindings" / "handle transport keys" lines — actual is one call: `debug.handle_input(&mut clock, &input)`
3. `orbit_controller.update(&mut camera)` — missing `&input` argument; actual signature is `update(&mut camera, &input: &dyn InputProvider)`

Fixed all three to match actual `viewer.rs` implementation.
